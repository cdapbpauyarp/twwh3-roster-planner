## Overview

Total War: Warhammer III Roster Planner provides a comprehensive army composition tool covering all factions including Champions of Chaos and Immortal Empires races, with unit recruitment cost calculations, army-wide stat summaries, lord and hero skill tree planning, and a composition score assessing battle line, flanking, and artillery balance.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Total War Warhammer III Roster Planner** delivers the features you need in a clean, intuitive package.
